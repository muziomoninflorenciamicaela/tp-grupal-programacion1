 # TRABAJO PRÁCTICO GRUPAL segundo parcial PROGRAMACIÓN I 2026
Muzio Monin, Ruíz y Pisani.
 ## Tema seleccionado: AUTOS, Taller mecánico.
Nuestro proyecto simulará un algoritmo creado con el fin de mantener un orden sobre los vehículos en un taller mecánico para su reparación.
El programa permite ingresar la patente, la marca, la cantidad de horas estimadas para la reparación y el precio de arreglo de cada vehículo.
