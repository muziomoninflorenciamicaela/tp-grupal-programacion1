 # TRABAJO PRÁCTICO GRUPAL segundo parcial PROGRAMACIÓN I 2026
Muzio Monin, Ruíz y Pisani.
 ## Tema seleccionado: AUTOS, Taller mecánico.
Nuestro proyecto simulará un algoritmo creado con el fin de mantener un orden sobre los vehículos en un taller mecánico para su reparación.
El programa permite definir la cantidad de registros a ingresar, contando cada uno con la patente del auto, la marca, la cantidad de horas estimadas para la reparación y el precio de arreglo de cada vehículo. Toda esta información se almacena en un archivo de texto y, a partir de ahí, se ofrecen opciones dentro de un menú: 
Opción 1: AGREGAR DATOS; Opción 2: Mostrar datos; Opción 3: Mostrar lista de autos con mas de 8 horas de reparación; Opción 4: Listar datos por marca a eleccion; Opción 5: ; Opción 0: Salir del sistema.
